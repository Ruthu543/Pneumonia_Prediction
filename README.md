🫁 Pneumonia Detection Web App
A full-stack web application that detects Pneumonia from chest X-ray images using deep learning (CNN). The system features user authentication, image upload, real-time predictions, PDF report generation, MongoDB integration, and a professional medical UI.

🛠️ Tech Stack
Layer	         Technologies
Frontend   :  React, HTML/CSS, React Router, Axios
Backend	   :  Node.js, Express, Flask (model serving)
Database   :  MongoDB + Mongoose
Model	   :  TensorFlow/Keras (CNN trained model)
Deployment :  Render / Heroku / Localhost
